## Définition du DevOps
Le DevOps est une façon d'associer le développement de logiciels et les opérations informatiques afin d'améliorer la collaboration, d'automatiser les processus et de livrer des applications plus rapidement et plus efficacement.

## Commandes Git utilisées pour réaliser ce travail
1. `git clone <url_du_depot>` (pour cloner le dépôt distant sur la machine locale)
2. `git status` (pour vérifier l'état des fichiers)
3. `git add .` (pour préparer tous les fichiers modifiés)
4. `git commit -m "Ajout des fichiers README.md, index.html et style.css"` (pour enregistrer les modifications dans l'historique)
5. `git push` (pour envoyer les modifications vers GitHub)
